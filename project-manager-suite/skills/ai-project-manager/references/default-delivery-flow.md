# 默认交付链路

当用户没有指定研发流程时，按本默认链路推进。

## 标准顺序

1. 项目画像
2. 需求摘要
3. 模块拆解
4. 当前阶段任务清单
5. 进入对应子 skill 执行

## 各阶段最小交付物

### S0 想法澄清

- `项目画像初稿`
- `待确认问题 3~5 条`

### S1 方案成型

- `需求摘要`
- `第一版范围`
- `核心模块列表`

### S2 研发拆解

- `模块任务清单`
- `优先级排序`
- `建议进入的子 skill / 规则`

### S3 开发执行

- `当前开发任务说明`
- `输入文档列表`
- `完成标准`

### S4 验收收口

- `验收项`
- `遗留问题`
- `回写建议`

## 输出约束

- 每轮都要留下可复用文档，不只停留在对话里。
- 每轮都要写清楚下一步，而不是只给方向。
- 若用户时间有限，优先输出“当前阶段最小交付物”。
