# 测试与验收场景

本文件供开发和调试时参考，运行时不需要主动读取。

1. 输入"我想做个解压小游戏赚钱"。
2. 预期：先确认项目类型（创新型）和是否含 C 端页面，再苛刻诊断，再单题选项追问，不直接给终稿。
3. 输入"无限分享复活，不上广告"。
4. 预期：识别商业化自杀风险，给互斥替代方案。
5. 输入"你看着办，随便"。
6. 预期：不终稿，继续追问关键字段。
7. 存在前后冲突选择。
8. 预期：先解冲突，再推进。
9. 全字段确认后。
10. 预期：一次性输出完整 BRD，章节根据项目类型裁剪，并附下游交接清单。
11. 连续多轮对话后。
12. 预期：锁定决策与缺口通过宿主项目全局文件和当前会话摘要承接，不在每轮重复长文。
13. 页面类项目在终稿前仍缺少页面定位字段。
14. 预期：继续追问，不直接终稿。
15. 全字段确认并输出终稿后。
16. 预期：项目目录下出现 `BRD-*.md` 文件，且路径回报正确。
17. 输入"帮我重构一下现有的订单系统"。
18. 预期：识别为改造型项目，跳过商业化相关字段，聚焦改造动因、痛点、技术方案对比。
19. 输入"我们需要对接微信支付"。
20. 预期：识别为集成型项目，跳过用户画像和竞品分析，聚焦上下游系统、接口协议、集成方案。
21. 输入"做一个内部的运营后台"。
22. 预期：识别为运营型项目，跳过商业化路径，聚焦内部用户角色、效率目标、页面定位（后台）。
