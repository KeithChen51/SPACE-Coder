# brd-writer

用毒舌评审+选项式提问逐轮收敛需求，产出可执行的 S1 阶段 BRD 文件。支持创新型、改造型、扩展型、集成型、运营型、合规型六种项目类型，根据类型动态裁剪字段和追问路径。

## 做什么

- 通过单题选项追问逐轮收敛需求
- 根据项目类型动态确定 P0 必填字段
- 判定是否包含 C 端页面（架构决策开关：含 C 端 → BFF）
- 产出结构化 BRD 文件，含下游交接清单

## 上游

| 上游 Skill | 消费的产物 | 读取的内容 |
|-----------|-----------|-----------|
| ai-project-manager | 项目画像、执行计划 | `project-profile.md`、`execution-plan.md`、已有 BRD 草稿 |

## 下游

| 下游 Skill | 提供的产物 | 用途 |
|-----------|-----------|------|
| page-designer | `BRD-<slug>-<YYYYMMDD-HHMM>.md` | 读取页面定位、C 端判定、用户画像、业务模型，据此设计可交互页面 |

## 产物

| 文件 | 说明 |
|------|------|
| `BRD-<slug>-<YYYYMMDD-HHMM>.md` | BRD 终稿，13 章 + 下游交接清单附录，根据项目类型裁剪章节 |
