# Phase 5: B 端权限矩阵

> 本文件在进入 B 端权限矩阵 Phase 时由 SKILL.md 指令加载。

## 目标

梳理 B 端所有角色与页面/菜单的可见性关系，产出页面级权限矩阵。

## 执行步骤

1. 从 BRD 中提取所有 B 端用户角色
2. 从 page-delivery 中提取所有 B 端页面和菜单结构
3. 对每个角色判断：哪些页面/菜单可见，哪些不可见
4. 若 BRD 中未明确角色定义，主动问用户
5. 交叉验证：权限矩阵中的角色是否与交互语义条目中的 `permission` 字段一致

## 产物结构

文件名：`explainer-b-permission-<slug>.md`

模板：读取 `templates/permission.md`

## 注意

- 粒度只到页面/菜单级，不细到按钮或字段
- 必须覆盖 B 端所有页面，不能遗漏
- 角色定义来自 BRD，不自创角色
