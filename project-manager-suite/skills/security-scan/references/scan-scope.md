# Security Scan Scope

## Default Full Scan Domains

### 1. 网络与暴露面

- 对外开放端口与不必要服务
- TLS 证书有效性与到期时间
- 管理端、调试端、健康检查端是否外露
- HTTP 安全头、CORS、限流、目录暴露

### 2. 应用代码安全

- 注入、命令执行、路径穿越、反序列化风险
- XSS、SSRF、模板注入、不安全文件上传
- 危险系统调用、临时绕过校验、调试开关残留

### 3. 认证与授权

- 弱认证、默认密码、会话管理缺陷
- JWT、Token、Cookie 使用不当
- 对象级越权、功能级越权、后台权限绕过

### 4. API 安全

- 未授权访问、批量操作滥用、资源耗尽
- 输入校验不足、输出过度暴露
- 第三方 API 调用链中的权限、签名、重放风险

### 5. 敏感信息与密钥

- 硬编码密钥、`.env` 泄漏、日志泄漏
- 私钥、证书、访问令牌、数据库凭证暴露
- 测试账号和临时密钥未隔离

### 6. 依赖与供应链

- 第三方依赖漏洞
- 锁文件漂移、来源不清、恶意包风险
- SBOM 缺失、制品来源不可追踪

### 7. 配置与部署加固

- 默认账号、危险默认配置、调试模式
- 容器特权、权限过大、存储公开
- 云资源、K8s、IAM 策略过宽

### 8. CI/CD 与运行时发布面

- 工作流注入、构建机权限过大
- 制品完整性不足、环境变量扩散
- 审计、告警、回滚准备不足
