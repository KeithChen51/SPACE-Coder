# Java 代码格式规范

> 来源：阿里巴巴 Java 开发手册 §1.3 代码格式 + §1.8 注释规约
> 适用：Java 代码格式化、注释编写

---

## 缩进与括号

1. 【强制】**4 个空格**缩进，禁止使用 tab。
2. 【强制】大括号 K&R 风格：左大括号前不换行、后换行；右大括号前换行；`else` 不换行。
3. 【强制】`if/for/while/switch/do` 与括号之间**必须加空格**。
4. 【强制】运算符左右两边各加一个空格。

## 行宽与换行

5. 【强制】单行不超过 **120 字符**，超出则换行：
   - 第二行缩进 4 个空格，第三行起不再继续缩进
   - 运算符、点号与下文一起换行
   - 逗号后换行，括号前不换行
6. 【强制】方法参数定义和传入时，逗号后必须加空格。

## 空行与空格

7. 【强制】注释双斜线与内容之间有且仅有一个空格：`// 注释内容`。
8. 【推荐】不同业务逻辑之间插入一个空行，相同语义之间不插入。
9. 【推荐】不必为对齐而增加多余空格。

## 编码设置

10. 【强制】文件编码 **UTF-8**，换行符 **Unix 格式**（LF）。

---

## 注释规约

11. 【强制】类、属性、方法注释使用 **Javadoc** 格式（`/** */`），不用 `//`。
12. 【强制】所有抽象方法（含接口方法）必须有 Javadoc：说明做什么、参数、返回值、异常。
13. 【强制】所有类必须标注创建者和创建日期。
14. 【强制】方法内单行注释在被注释语句**上方**另起一行，用 `//`。
15. 【强制】所有枚举字段必须有注释说明用途。
16. 【推荐】中文注释优先（本项目约定），专有名词保持英文。
17. 【推荐】代码修改时同步更新注释。
18. 【参考】无用代码直接删除，不要注释保留（Git 有历史记录）。
