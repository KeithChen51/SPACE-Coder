
## 3. SQL 文件命名

| 文件类型 | 命名 | 说明 |
|---------|------|------|
| 种子数据 | `{PREFIX}-SEED.sql` | 配置表初始数据，所有用例共用 |
| 场景数据 | `{PREFIX}-{NN}.sql` | 与用例编号一一对应 |

SQL 文件存放在各域子文件夹的 `sql/` 子目录中（如 `client/区块2-状态判定/sql/`）。

markdown 引用示例（相对于域文件夹内的 markdown 文件）：
- `> 执行 [sql/CTC-STA-01.sql](sql/CTC-STA-01.sql) 中的"数据准备"段`
- `> 复用 [sql/CTC-STA-01.sql](sql/CTC-STA-01.sql)`

## 4. 2 层文件名约定

当域文件需要拆分时：

| 层 | 命名规则 | 示例 |
|---|---------|------|
| 索引层 | `tc-{区块}-{域名}.md` | `tc-区块2-状态判定.md` |
| 详情层 | `tc-{区块}-{域名}-用例详情.md` | `tc-区块2-状态判定-用例详情.md` |

双向引用格式：
- 索引层头部：`> **用例详情**: [{详情文件名}]({详情文件名})`
- 详情层头部：`> **索引文件**: [{索引文件名}]({索引文件名})`

## 5. 权威索引文件

| 文件 | 路径 | 用途 |
|------|------|------|
| 权威索引 | `docs/test-case/tc-主文档.md` | 全部域文件的注册索引、状态、统计 |
| 编号规则 | `docs/test-case/README.md` | 目录结构说明 + 编号规则 |
| 编码规范 | `docs/coding-standards/11-test-case-design.md` | 测试用例设计的项目编码规范 |

生成域文件后必须更新 `tc-主文档.md`：将状态从"待编写"改为"已完成"，同步编号前缀和文件名。

## 6. 关键业务样本类型

本项目的关键业务状态，用于构建稳定测试样本字典：

| 样本类型 | 业务含义 |
|---------|---------|
| 新车 (NEW) | 首次进场、无历史工单 |
| 超期 (OVERDUE) | 超出保养周期 |
| 维保中 (REPAIR) | 当前有进行中的维修工单 |
| 正常 (NOT_DUE/DUE) | 正常保养周期内 |
| 有券 | 持有保养券/优惠券 |
| 有保险 | 有生效中的保险保单 |
