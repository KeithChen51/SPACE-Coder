# 管理台配置测试 — 生成策略 + 模板

## 生成策略

- 按配置页面分组
- 每组覆盖：CRUD 操作 → 配置生效验证 → 边界校验
- 预期结果要验证"保存后数据库状态"和"前端展示更新"
- 执行方式：浏览器 UI + 数据库查询
- 数据准备：管理台 API 调用或 SQL（构造初始配置状态）
- 数据清理：还原配置到测试前状态

---

## 测试范围表

```markdown
## 一、测试范围

本文件覆盖 **{配置页面名称}** 的配置管理和生效验证。

| 配置功能 | PRD 章节 | 测试重点 |
|---------|---------|---------|
| {功能A} | §X.X | CRUD + 生效验证 |
```

## 用例模板

```markdown
### {PREFIX}-{NN}：{用例标题}

> PRD：`{文档名}` §{章节号}
> 目标：验证{配置操作的正确性和生效}
> 执行方式：浏览器 UI + 数据库验证

**前提条件**：
- 管理台前端已启动
- {当前配置状态（人类可读描述）}

**数据准备**：
```sql
-- 构造初始配置状态
INSERT INTO {配置表} ({字段列表}) VALUES ({初始值});
-- 或通过管理台 API：
-- curl -X POST http://localhost:8080/admin/api/{配置接口} -d '{初始配置JSON}'
```

**步骤**：
1. 打开管理台 `{URL}`
2. {操作：新增/编辑/删除 配置项}
3. 点击保存
4. 检查数据库 `SELECT * FROM {配置表} WHERE {条件}`

**预期结果**：

| 检查项 | 预期 |
|:---|:---|
| 前端提示 | {保存成功提示} |
| 数据库 {配置表}.{字段} | {目标值} |
| 列表页展示 | {更新后的展示} |

**数据清理**：
```sql
DELETE FROM {配置表} WHERE {条件};
```
