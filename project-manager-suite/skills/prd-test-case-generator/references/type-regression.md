# 缺陷回归测试 — 生成策略 + 模板

## 生成策略

- 每个缺陷至少一条回归用例
- 用例重现原始缺陷场景，验证修复后的正确行为
- 标注缺陷编号，便于追踪
- 使用错误推测法补充相关边界用例
- 数据准备：构造原缺陷触发条件的 SQL 或 API 调用

---

## 用例模板

```markdown
### {PREFIX}-{NN}：{缺陷标题回归}

> 关联缺陷：{缺陷编号}（{缺陷简述}）
> PRD：`{文档名}` §{章节号}
> 目标：验证{缺陷修复后的正确行为}
> 执行方式：{按原缺陷场景}

**前提条件**：
- {重现原缺陷的环境条件（人类可读描述）}

**数据准备**：
```sql
-- 构造原缺陷触发条件
INSERT INTO {表名} ({字段列表}) VALUES ({原缺陷触发数据});
```

**步骤**：
1. {重现原缺陷的操作步骤}
2. {检查修复后行为}

**预期结果**：

| 检查项 | 预期（修复后） |
|:---|:---|
| {原缺陷表现} | {正确行为} |

**数据清理**：
```sql
DELETE FROM {表名} WHERE {条件};
```
```
