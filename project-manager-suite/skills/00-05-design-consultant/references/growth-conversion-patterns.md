# 增长与转化模式

这八类模式吸收 S2 原 `landing.csv` 的 34 种落地页结构，但不继承其固定颜色、动效、未经证明的转化数字或暗黑模式建议。增长页面仍受项目设计系统、C 端体验契约和真实证据约束。

## 统一字段

每次选型必须写明：`Goal`、`Evidence`、`Primary CTA`、`Secondary CTA`、`Mobile`、`Accessibility`、`Forbidden`。同一视口只设一个主要行动；次行动不能伪装成主要行动，也不能以视觉弱化隐藏退出或拒绝。

## 八类受控模式

### `value-cta`

- Goal：让目标用户在首屏理解“解决什么、适合谁、下一步是什么”。
- Evidence：真实能力、适用边界、关键收益的来源，不用无出处的倍率。
- Primary CTA：开始试用、查看方案或进入核心任务之一。
- Secondary CTA：了解细节、查看案例或联系支持。
- Mobile：价值、证据和主行动先出现；不复制多组粘性 CTA。
- Accessibility：标题顺序、焦点顺序和视觉顺序一致，CTA 文案说明结果。
- Forbidden：虚假稀缺、误导倒计时、强迫连续浏览。
- 历史来源：1 Hero + Features + CTA；4 Minimal Single Column；5 Funnel；31 Feature-Rich Showcase；32 Hero-Centric Design。

### `product-demo`

- Goal：用真实界面、前后结果或可控交互解释产品如何工作。
- Evidence：实际截图/录屏、可复现输入输出、数据更新时间和能力限制。
- Primary CTA：试用演示、开始配置或进入真实产品。
- Secondary CTA：查看说明、兼容性或技术细节。
- Mobile：重交互退化为分步演示；视频不强制自动播放并提供字幕。
- Accessibility：演示有键盘路径、文本替代、暂停控制和 reduced-motion 版本。
- Forbidden：伪造实时数据、把概念动画冒充成已实现产品、不可停止的背景视频。
- 历史来源：3 Product Demo；9 Video-First；21 Before-After；28 Bento；29 3D Configurator；30 AI Dynamic；34 Real-Time Operations。

### `social-proof`

- Goal：用第三方或真实用户证据降低信任成本。
- Evidence：可核验的姓名/角色/关系、评价样本量、日期、验证方法和利益关系。
- Primary CTA：在理解证据后进入试用、购买或加入。
- Secondary CTA：查看完整案例、评价方法或社区规则。
- Mobile：摘要先行，长评价按需展开；头像轮播不是唯一证据入口。
- Accessibility：轮播可暂停，评分不只用颜色或星形，引用保留语义结构。
- Forbidden：伪造客户标识、选择性隐瞒负面评价、虚报人数和活动量。
- 历史来源：2 Testimonials；19 Ratings；20 Community；33 Trust & Authority。

### `pricing-comparison`

- Goal：帮助用户按同一口径比较费用、权益、周期和限制。
- Evidence：完整应付金额、税费、续费日期、功能边界和退款取消条件。
- Primary CTA：选择明确套餐或继续到交易复核。
- Secondary CTA：联系咨询、查看完整差异或继续使用免费方案。
- Mobile：逐维度比较，价格和周期常显；不能只给横向宽表。
- Accessibility：推荐理由可读，切换周期后主动播报价格变化，表格保留行列关系。
- Forbidden：预选付费套餐、隐藏循环收费、把月均价冒充本次扣款、阻碍取消。
- 历史来源：6 Comparison + CTA；8 Pricing Page；13 Comparison Focus；14 Pricing-Focused。

### `lead-signup`

- Goal：以清楚的交换价值收集最少必要资料或完成活动报名。
- Evidence：用户将获得什么、何时获得、谁处理数据、后续联系频率。
- Primary CTA：提交资料、报名或订阅。
- Secondary CTA：预览内容、查看议程/讲者、直接联系或拒绝。
- Mobile：单列短表，键盘不遮挡提交，错误贴近字段并保留输入。
- Accessibility：标签常显、错误可定位、成功有文字确认、时区自动推断可修改。
- Forbidden：同意捆绑、隐藏营销订阅、为查看基本资料强制留资、默认勾选额外联系。
- 历史来源：7 Lead Magnet；16 FAQ/Documentation；18 Event；23 Newsletter；24 Webinar；25 Enterprise Gateway。

### `launch-app-download`

- Goal：承接候补、发布、下载和跨设备安装。
- Evidence：真实上线状态、支持平台/地区、实际截图、候补规则和数据用途。
- Primary CTA：加入候补、前往对应商店或下载。
- Secondary CTA：查看演示、兼容性、发布更新或撤回登记。
- Mobile：只显示当前设备可用入口；桌面提供可验证二维码和后续邮件选项。
- Accessibility：二维码必须有等价链接，倒计时若存在必须有来源且不限制内容读取。
- Forbidden：误导倒计时、虚假候补人数、伪造商店评分、用稀缺感强迫分享。
- 历史来源：12 Waitlist/Coming Soon；15 App Store Style。

### `marketplace-directory`

- Goal：让用户从类目、位置或搜索快速进入真实供给。
- Evidence：供给数量口径、服务范围、排序逻辑、资质和平台保障。
- Primary CTA：搜索或浏览候选项。
- Secondary CTA：成为供给方、查看保障或调整位置。
- Mobile：搜索先行；地图与列表可切换并共享选择状态。
- Accessibility：地图有列表替代，位置权限可拒绝，筛选结果变化可感知。
- Forbidden：隐藏无结果、默认扩大定位权限、付费排序不披露。
- 历史来源：22 Marketplace / Directory。

### `story-immersive`

- Goal：用叙事、作品或互动体验建立理解，同时让用户随时掌控节奏。
- Evidence：作品归属、案例上下文、互动结果的真实性和性能边界。
- Primary CTA：查看作品、体验产品或进入下一明确章节。
- Secondary CTA：跳过动画、打开目录、查看文字版或联系作者。
- Mobile：线性叙事退化为自然滚动；横向滚动、3D 和个性化必须有轻量替代。
- Accessibility：可暂停、可跳过、键盘可达、reduced-motion 下内容和行动不丢失。
- Forbidden：强迫连续滚动、不可退出的沉浸模式、根据敏感属性暗中个性化。
- 历史来源：10 Scroll Storytelling；11 AI Personalization；17 Immersive；26 Portfolio Grid；27 Horizontal Journey。

## 禁止项总表

无论选哪一类，都禁止：fake scarcity（虚假稀缺）、preselected paid plans（预选付费方案）、hidden recurring fees（隐藏循环收费）、forced continuity（强迫连续流程）、misleading countdowns（误导倒计时）、obstructed cancellation（阻碍取消）和 consent bundling（同意捆绑）。增长目标不能覆盖交易复核、隐私选择、可访问性或恢复能力。
