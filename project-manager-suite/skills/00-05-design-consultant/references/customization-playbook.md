# 低成本客制化方法

轻客制化的目标是让项目有明确气质，同时不推翻部门默认组件系统。

## 可客制化杠杆

只从以下杠杆中选择，不要每次重做完整设计系统：

1. 主色 seed。
2. 信息密度。
3. 圆角性格。
4. 字体策略。
5. 视觉强度。
6. 场景模板。

## 主色 seed

用户提供一个品牌色或业务色后，生成：

- primary
- primary-hover
- primary-soft
- focus-ring
- link

规则：

- 只改变强调色，不改变语义色含义。
- 背景和文本仍优先使用默认中性色。
- 主色必须通过按钮文字对比度检查。

## 信息密度

| 密度 | 用途 | 调整 |
|---|---|---|
| compact | 后台、表格、运营工具 | 行高小、间距 8-16px |
| standard | 普通业务系统 | 间距 12-24px |
| spacious | 对外展示、管理层汇报 | 间距 24-48px |

## 圆角性格

| 类型 | 按钮 | 卡片 | 弹窗 | 气质 |
|---|---:|---:|---:|---|
| sharp | 4px | 4px | 8px | 工具、专业 |
| standard | 6px | 8px | 12px | 默认、耐用 |
| soft | 10px | 12px | 16px | 亲和、消费化 |

一个项目只能选择一种圆角系统。

## 字体策略

| 策略 | 字体 |
|---|---|
| system | 默认系统字体 |
| data-heavy | 系统字体 + tabular nums + 等宽数字 |
| corporate | 企业指定字体或系统 fallback |
| editorial | 仅在展示/内容型页面中使用更强标题字体 |

如果没有品牌字体，内部工具优先使用 system，不要为了差异化引入远程字体。

## 视觉强度

| 强度 | 规则 |
|---|---|
| quiet | 少色、少阴影、少装饰，适合高频业务 |
| confident | 明确主色、清楚层级，适合长期业务产品 |
| expressive | 更强标题、图像或动效，仅适合对外/展示 |

## 输出模板

```markdown
建议走轻客制化：
- 主色：从 #0F766E 生成 teal 系列。
- 密度：compact，因为主要是运营人员高频使用。
- 圆角：standard，避免过度消费化。
- 字体：system，减少加载和维护成本。
- 视觉强度：confident，主操作和状态更明确，但不做营销化装饰。
```
