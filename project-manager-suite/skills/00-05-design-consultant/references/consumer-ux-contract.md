# C 端体验契约

本契约定义 C 端页面生产和验收的最低要求，覆盖 mobile、keyboard 与 accessibility。WCAG、颜色对比、焦点可见性、reduced-motion、浅色/深色（dark）主题和组件状态继续引用现有 `ux-review-checklist.md`、`motion-polish.md` 与 Token 契约，不在这里另建一套标准。

## 移动与触控

- 交互目标至少 `44px × 44px`；相邻高风险操作必须留出防误触间距。
- 固定底栏、购买按钮、播放器和浮层必须处理 `safe-area-inset-*`，且不遮挡最后一项、错误或系统键盘。
- 移动端按任务重排，不把桌面多栏、宽表或复杂比较等比缩小。
- 横向手势必须有按钮、列表或其他可发现的替代路径。

## 导航、返回与状态保留

- 返回必须回到可预期位置；搜索、筛选、排序、页码、滚动位置和已选对象在合理周期内保留。
- 登录、支付、外部授权或商店跳转完成后，回到触发它的任务而非通用首页。
- 离开有未保存内容的页面前给出明确选择；自动保存时显示最近保存状态。
- 深链进入时仍提供当前位置、上级路径和退出路径。

## Onboarding 与权限

- Onboarding 默认可跳过或稍后完成，只有法律、账户安全或核心功能确实必需时才能阻断，并解释原因。
- 逐项申请权限，在用户触发相关功能时说明用途；拒绝后提供有限能力或设置入口。
- 注册只收集完成当前任务所需字段；营销同意与服务条款分别选择。
- 身份验证失败保留非敏感输入，说明可重试、换方式和账户恢复路径。

## 搜索、表单与反馈

- 搜索建议、请求中、无结果、部分结果和失败是不同状态；无结果必须保留查询并提供调整路径。
- 字段标签常显，校验贴近字段并给出修正办法；提交失败不清空合法输入。
- loading 不使用空白页面；empty 只用于已确认无数据；partial 明确哪些内容不可用；error 给出可执行恢复动作；success 说明结果和下一步。
- 通知按任务紧迫性分级，可延后的消息不反复打断用户；重要结果不能只靠短暂 Toast。

## 交易与不可逆操作

- 支付、预约、订阅变更、公开发布和删除前必须 explicit transaction review：对象、金额/影响、时间、责任主体和撤销条件清楚可见。
- 处理过程中阻止重复提交但保留状态查询；结果页给出稳定凭证，不只显示庆祝动画。
- 价格必须同时标明币种、计费周期、税费/附加费和本次应付金额；自动续费显示首次与下次扣费日期。
- 高风险操作不预选，不与高频安全操作相邻，也不以颜色作为唯一警告。

## 失败与恢复

- Payment：区分拒付、超时、处理中和未知结果；未知时先查订单，不诱导重复付款。
- Booking：时段失效时保留联系人和其他选择，说明原因并提供相邻可用时段。
- Upload：显示单项进度和失败原因，允许重试失败项，不要求全部重传；离开前说明后台上传状态。

## 用户可见数据与文案

- 读取 `references/user-facing-content-boundary.md`。页面不得直接显示数据库字段、API field、raw enum、内部状态码、对象 dump、debug/mock/placeholder 文案、服务端异常或源码路径。
- 状态、类型、金额、时间、权限、错误和空值必须经过 presentation mapping；未知值使用安全业务 fallback，不能回退为内部原值。
- loading、empty、partial、error、success 与恢复状态都要检查 visible text；移动端不能因为空间不足改为展示内部缩写或代码值。
- Subscription changes：显示生效时间、权益变化、差价和撤销条件；失败保持原套餐有效并给出恢复路径。
- 弱网、离线、权限不足和会话过期都必须有页面内反馈，恢复后尽量继续原任务。

## 键盘、可访问性与主题

- 所有主要流程可用 keyboard 完成；焦点顺序跟随阅读顺序，弹窗关闭后焦点返回触发点。
- 图标、评分、状态和图表语义不能只依赖颜色；媒体提供字幕、文字替代或摘要。
- 浅色和 dark 主题共用语义 Token；切换主题不改变信息优先级或隐藏状态。
- 动效遵守 reduced-motion，禁用动效后 loading、进度、成功和错误仍可理解。

## 验收最小视口

至少验证一个桌面视口和一个移动视口；包含浅色/深色主题（若项目声明支持）、键盘路径、loading、empty、partial、error、success、返回恢复，以及真实项目要求的支付、预约、上传或订阅恢复场景。每个场景同时检查用户可见文案、控件名称、placeholder 与展示值是否符合内容边界。检查证据由阶段测试产物保存，本 skill 只提供规则和判定依据。
