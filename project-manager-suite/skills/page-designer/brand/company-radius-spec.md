## 使用说明

圆角分为 3 种类型：
- 小圆角
- 中等圆角
- 大圆角

## 使用规则 / 场景

大部分的场景使用 8pt、12pt。

| 圆角大小 | 使用规则 / 场景 |
|----------|----------------|
| 小 — 4pt | 用于小标签、小按钮 |
| 中等 — 8pt | 用于大按钮、中按钮、气泡弹层 |
| 较大 — 12pt | 主要用于页面中卡片、弹窗、Toast |
| 最大 — 16pt | 主要用于底部大的卡片，如面板 |

## 使用场景案例

- **圆角 8pt**：列表页按钮（如 Follow / Following / Friend 按钮）
- **圆角 12pt**：页面主卡片（如车辆信息卡片、地图卡片、功能入口卡片）、弹窗（如提示说明弹窗，内容说明当前状态、提示用户解决方案，超过两行需左显示）
