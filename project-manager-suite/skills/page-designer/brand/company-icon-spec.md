# 公司图标设计规范（从内部截图提取）

> 来源：系统图标.png（公司内部设计规范文档截图）
> 提取时间：2026-04-08
> 用途：page-designer 在生成页面时遵循的图标规范约束

---

### 1 设计原则

| 原则 | 说明 |
|------|------|
| 简约 | 图标的造型告别繁杂，不做过多的装饰，有较高的易读性和辨识性 |
| 清晰 | 清晰是保证设计品质的前提，需保证在各个平台上图标都有着清晰的阅读性 |
| 一致性 | 图标中的风格，如圆角度、粗细等都需要保持一致性 |

### 2 图标尺寸

| 用途 | 尺寸 |
|------|------|
| 标准图标 | 24 x 24 px |
| 大图标 | 32 x 32 px |

### 3 图标网格

预设正方形、圆形、矩形、正交线、对角线以及内容区域，去辅助图标的设计，以达到一致的视觉面积。在绘制图标时，元素与像素网格对齐以确保清晰。

### 4 简约造型

图标造型建议化繁为简，避免笔画过多，保持图标简约、干净。

**判断标准：**
- 正确：笔画精简，轮廓清晰（如简洁的耳机图标）
- 错误：笔画过多，细节冗余（如添加了多余话筒线的耳机图标）

### 5 粗细

- 统一粗细：**1.5pt**（即 4.5px）

### 6 图形圆角

- 圆角半径：**2pt**（即 3 倍图上 6px）
- 外部与内部均为圆角，整体圆润、亲和

### 7 线形和面形

若线性图标使用中需要有对应的面形造型，在绘制两种对应图标时，需确保图标轮廓、大小一致。

### 8 图标状态

| 状态 | 规则 |
|------|------|
| 按压态 | 50% 不透明度 |
| 置灰态 | 30% 不透明度 |

### 9 图标热区

点击热区为图标尺寸的 **2 倍**：

| 图标尺寸 | 热区尺寸 |
|----------|----------|
| 24 x 24 | 48 x 48 |
| 32 x 32 | 64 x 64 |

### 10 命名规则

命名逻辑顺序：`ic_模块_功能_位置_颜色_状态_数字`

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| ic | 必填 | 固定前缀 |
| 模块 | 必填 | 所属模块 |
| 功能 | 必填 | 图标功能 |
| 位置 | 选填 | 图标位置 |
| 颜色 | 选填 | 图标颜色 |
| 状态 | 选填 | 图标状态 |
| 数字 | 选填 | 序号 |

规则约束：
- 资源名全部为**小写字母**
- 长字段可以尽量用缩写
- 命名中**不能有空格**
- 不同字段之间以 `_` 分隔

### 11 图标模块分类

| 模块 | 尺寸 | 说明 |
|------|------|------|
| 公共模块 | 24 x 24 | 返回、搜索、保存、分享、筛选、扫码、删除、首页、时间、编辑、更多、电话、收藏、麦克风等通用图标 |
| 服务模块 | 24 x 24 | 业务相关图标 |

> 注：爱车页功能图标需要与车端对齐，其他图标设计师可自行评估。
